Export & Import Data

💾 Export Products JSON

Download the current products data as a products.json file. Replace the file at frontend/data/products.json to update the live site.

💾 Export Brands JSON

Download the current brands data as a brands.json file. Replace the file at frontend/data/brands.json to update the live site.

📄 Import Products CSV

Upload a CSV file with product data. Columns: id, name, brand, category, tags, material, capacity, active

ℹ How to Update the Live Site

  1. Use the admin panel to add/edit products and brands
  2. Click "Download products.json" or "Download brands.json"
  3. Replace the files in the frontend/data/ folder of the website
  4. The website will automatically show the updated data

Note: Changes made here are stored in your browser (localStorage) until you export. Data is NOT lost on page refresh.
